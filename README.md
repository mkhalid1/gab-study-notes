# GAB対策ノート（日本SHLの総合適性検査）

日本エス・エイチ・エルの総合適性検査GABの無料学習ガイドです。試験の仕組み、言語理解（長文の論理判断）と計数理解（図表の読み取り）の解き方、受検形式（WebGAB・C-GAB plus・紙のGAB）の違い、玉手箱との違い、性格検査（OPQ）、結果の見方、7日間と2日間の学習プランをまとめました。試験についての事実は日本SHLの公開ページだけを根拠にし、[出典](docs/sources.md)を明記しています。公式に公開されていない数字は、そうとわかるように書いています。

まず実力を知りたい方は、[PrepClubsの無料GAB形式模試](https://prepclubs.com/ja/gab-taisaku?utm_source=github&utm_medium=referral&utm_campaign=99ayax&utm_content=gab)か、このリポジトリの短い[10分診断テスト](docs/diagnostic.md)から始めてください。

## はじめに

1. 苦手な科目を知る。[10分診断テスト](docs/diagnostic.md)で、言語と計数を2問ずつ解きます。
2. 苦手な科目から直す。下の表から科目のページを開き、選択肢の判断基準と手順を読んでから、練習問題5問を解きます。
3. プランに沿って進める。[7日間プラン](docs/study-plans.md#7日間プラン)、受検案内がもう届いているなら[2日間プラン](docs/study-plans.md#2日間プラン)を使ってください。

## 基本情報

| 項目 | 内容 |
|---|---|
| 提供元 | 日本エス・エイチ・エル株式会社 |
| 測定項目 | 言語・計数・英語・パーソナリティ（OPQ） |
| 所要時間合計 | 80〜90分（公式表記） |
| 英語 | テストセンター方式のみ |
| 受検形式 | Web（WebGAB）、テストセンター（C-GAB plus）、マークシート（紙のGAB） |
| ノルム | 大卒 |
| 結果 | 10段階の標準点 |
| 合格点 | 公表なし。基準は企業ごとに違う |
| 科目ごとの問題数・制限時間 | 公式の公開ページには記載なし（[非公式の目安](docs/versions.md#問題数と制限時間の目安非公式)） |

出典：[日本SHL GAB製品ページ](https://www.shl.co.jp/service/assessment/gab/)、[【公式解説】総合適性検査GABとは？](https://www.shl.co.jp/column/perspective/250905_gab/)。2026年11月25日に確認。

## 科目の一覧

| 科目 | 何をするか | 選択肢 | ページ |
|---|---|---|---|
| 言語理解（論理） | 400〜800字程度の長文を読み、設問文を判定する | A 明らかに正しい、B 明らかに間違っている、C 判断できない | [言語理解](docs/sections/gengo.md) |
| 計数理解（図表理解） | 図表を読み取り、割合や増減率を計算する | 選択肢から1つ | [計数理解](docs/sections/keisu.md) |
| 英語（大意） | 50〜80語程度の英文を読み、答えを英語で選ぶ。テストセンター方式のみ | 英語の選択肢 | [受検形式](docs/versions.md#英語テストセンター方式のみ) |
| 性格検査（OPQ） | 4つの記述から最も近いものと最も遠いものを選ぶ | 正解なし | [性格検査](docs/personality-opq.md) |

言語と計数のページは同じ構成です。何を測る科目か、問題の形式、解き方の手順、ミスしやすいポイント、時間配分、オリジナルの練習問題5問と解説、自己採点の表が入っています。

## このリポジトリの使い方

- GitHub上でそのまま読めます。どのページにも前のページ、次のページ、目次へのリンクがあるので、本のように順番に読み進められます。
- 答えは「解答と解説」の中に隠してあります。開く前に、自分の答えを決めてください。
- 正解した問題の解説も読んでください。多くの解説には、近い選択肢がなぜ違うのかを書いてあります。
- 間違いの記録をつけてください。書き方は[学習プラン](docs/study-plans.md#間違えた問題の見直し方)にあります。
- 時間を計って練習してください。このガイドで学べるのは解き方です。ペースは、[PrepClubsの無料模試](https://prepclubs.com/ja/gab-taisaku?utm_source=github&utm_medium=referral&utm_campaign=99ayax&utm_content=gab)のような通しの練習で身につきます。
- 書き込み用に、クローンやフォークをしても構いません。GitBookのスペースとしても使える構成です（[SUMMARY.md](SUMMARY.md)）。

## 練習問題について

練習問題は全14問（言語5問、計数5問、診断テスト4問）で、すべてこのガイドのために書いたオリジナルです。GABの実際の問題、日本SHLの資料、ほかの対策サイトから取ったものはありません。日本SHLが公開している科目の説明に沿って作っているので、ここで身につけた手順は本番の形式にもそのまま使えます。

## 誤りを見つけたら

事実の誤り、情報の変更、答えが別だと思う問題があれば、[Issue](https://github.com/mkhalid1/gab-study-notes/issues)かプルリクエストで知らせてください。事実の訂正には、日本SHLや企業の公式ページへのリンクを添えてください。
