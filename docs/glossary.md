# 用語集

GABの対策でよく出てくる言葉をまとめました。

| 用語 | 意味 |
|---|---|
| GAB | Graduate Aptitude test Battery の略。日本エス・エイチ・エルの総合適性検査 |
| 日本SHL | 日本エス・エイチ・エル株式会社。GAB、玉手箱Ⅲ、CABなどを提供している |
| WebGAB | 自宅などのパソコンで受けるWebテスト形式のGAB。就活生のあいだでは「Web-GAB」とも書かれる |
| WebGAB Plus One | 言語・計数に任意の知的能力科目を1つ追加できるWebGAB |
| WebGAB Secure | AIによる監視機能（AIプロクタリング）がついた不正対策型のWebGAB |
| C-GAB plus | テストセンター形式のGAB。英語が加わる。就活生のあいだでは「C-GAB」と呼ばれることが多い |
| 紙のGAB | 問題冊子とマークシートで受けるGAB。「筆記GAB」とも呼ばれる |
| 言語理解（論理） | GABの言語科目。長文の論理から、設問文が正しいか、間違っているか、判断できないかを選ぶ |
| 計数理解（図表理解） | GABの計数科目。図表を読み取って計算する |
| 英語（大意） | テストセンター方式のみの英語科目。50〜80語程度の英文を読む |
| OPQ | Occupational Personality Questionnaires の略。GABに含まれる性格検査 |
| イプサティブ（強制選択）形式 | 4つの記述から最もあてはまるものと最もあてはまらないものを選ぶ回答形式 |
| ノーマティブ形式 | 1つの記述ごとに「あてはまる・あてはまらない」を答える回答形式 |
| ノルム | 得点を比べる基準になる集団。GABは大卒 |
| 標準点 | ノルムの中での位置を表した得点。GABは10段階 |
| AIプロクタリング | AIによる受検中の監視。顔認証や行動の監視で不正を検知する |
| 玉手箱Ⅲ | 日本SHLの別の適性検査。言語（大意把握）、計数（四則逆算）、英語、OPQで構成される |
| 構成比 | 全体に占める各部分の割合（％） |
| 増加率 | （今回の値 − 前回の値）÷ 前回の値 |
| 達成率 | 実績 ÷ 目標 |
