# 採点と結果の見方

先に結論を言うと、GABの結果は10段階の標準点で出ます。日本SHLは合格点やボーダーラインを公表しておらず、どの点数を求めるかは企業ごとに違います。このページでは、公式に公開されている結果の仕組みと、そこから言える準備の考え方をまとめます。

## 標準点（10段階）

日本SHLの公式解説によると、GABの得点は「標準点と呼ばれる10段階の得点」ですべて算出されます。一般に標準点とは、正解した数をそのまま使うのではなく、基準になる集団の中での位置を段階で表した得点のことです。日本SHLの公開ページには、GABの標準点の細かい算出方法までは書かれていません。

製品ページでは、GABのノルム（比較の基準になる集団）は「大卒」とされています。つまり、同じ正答数でも、それが大卒の受検者の中でどのくらいの位置かによって標準点が決まります。

| 用語 | 意味 |
|---|---|
| 正答数 | 正解した問題の数 |
| ノルム | 得点を比べる基準になる集団。GABは大卒 |
| 標準点 | ノルムの中での位置を10段階で表した得点 |

## 結果表に出る内容

公式解説によると、結果表には次のような内容が出力されます。

- 知的能力の得点
- 性格検査から予測される、仕事上求められるコンピテンシー（「ヴァイタリティ」「チームワーク」など）
- 将来のマネジメント適性
- 職務適性（「営業」「研究／開発」など）
- 受検者の強みや弱みに関するコメント

結果表のサンプルは、日本SHLへの問い合わせで企業向けに案内されるもので、受検者が結果を見られるかどうかは企業によります。

## 合格点はあるのか

日本SHLの公開ページには、合格点もボーダーラインも書かれていません。就活サイトでは「7割」「8割」といった数字が紹介されることがありますが、公式の根拠はありません。企業がどの得点を基準にするか、知的能力と性格検査をどう組み合わせて見るかは、企業ごとに決まっています。

また、GABの結果は選考の足切りだけに使われるわけではありません。公式ページでは、面接で確認するポイントを絞る、内定者へのフィードバックに使う、配属を考える、といった活用法が紹介されています。

## 誤答の扱い

誤答が減点されるかどうかは、公式の公開ページには書かれていません。就活サイトでもさまざまな説明があり、確かなことは言えません。このガイドでは、根拠のない推測で解き方を決めるより、次の方針をおすすめします。

- わからない問題に時間を使いすぎない。1問に固執して後半の問題に手をつけられないのが、いちばんもったいない失点です。
- 勘で埋めるかどうかは、受検前の案内に注意書きがあればそれに従う。

## 練習での目標の立て方

公式の合格点がない以上、目標は自分で決めるしかありません。このガイドの目安は次のとおりです（公式の基準ではありません）。

| 練習の段階 | 目安 |
|---|---|
| 形式に慣れる段階 | 時間を気にせず、練習問題の8割以上を根拠つきで正解できる |
| 時間を計る段階 | 制限時間内に最後の問題まで手をつけ、正答率が大きく落ちない |
| 仕上げの段階 | 通しの模擬テストで、言語・計数のどちらにも極端な弱点がない |

## 対策で点数は変わるのか

公式解説は、GABはちょっとした対策で得点が大きく変わるテストではないとしています。そのうえで、問題形式や制限時間、解き方をよく理解し、練習してから受けることを勧めています。形式を知らないまま受けると、本来の力より低い結果になりやすいということです。準備の目的は、実力以上の点を取ることではなく、実力どおりの点を取ることだと考えてください。
