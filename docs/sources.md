# 出典

試験についての事実は、提供元である日本エス・エイチ・エルとSHLグループの公開ページだけを根拠にしています。すべて2026年11月25日に内容を確認しました。

## 提供元：日本エス・エイチ・エル

- [GAB製品ページ](https://www.shl.co.jp/service/assessment/gab/)：測定項目、所要時間合計（80〜90分）、ノルム（大卒）、実施形態、言語・計数・英語・性格検査の説明、活用法
- [【公式解説】総合適性検査GABとは？](https://www.shl.co.jp/column/perspective/250905_gab/)（2025年9月5日公開）：GABの名前の由来、3つの実施形式、言語の選択肢A・B・C、計数の内容、OPQの回答形式、標準点（10段階）、結果表の内容、対策についての見解
- [WebGAB Secure](https://www.shl.co.jp/service/assessment/gab/webgabsecure/)：AIプロクタリング、受検環境、形式ごとの比較
- [WebGAB Plus One](https://www.shl.co.jp/service/assessment/webgabplusone/)：追加科目、所要時間合計（89〜100分）
- [C-GAB plusのご案内](https://www.shl.co.jp/materials/c-gabplus/)：テストセンター形式とWeb会場での受検
- [玉手箱Ⅲ製品ページ](https://www.shl.co.jp/service/assessment/tamatebako3/)：玉手箱Ⅲの科目と所要時間（49分）
- [SHLの適性検査（玉手箱Ⅲ・GAB・CAB・RAB）を徹底比較](https://www.shl.co.jp/column/perspective/220617ysato/)（2026年2月6日更新）：玉手箱Ⅲ、GAB、CAB、RABの比較
- [WebOPQ製品ページ](https://www.shl.co.jp/service/assessment/opq/)：OPQの3つの領域と30の因子、回答形式、対応言語

## SHLグループ

- [SHL Direct 日本：模擬テスト](https://www.shl.com/shldirect/jp/practice-tests/)：公式の模擬テストサイト。言語・計数・法則性の練習テストは日本語版がなく、英語版のみと記載

## 非公式の情報（公式の数字ではないもの）

- [ワンキャリア「【GAB対策】全種類の問題＆解答集」](https://www.onecareer.jp/articles/3506)：受検形式ごとの問題数と制限時間の目安、電卓の扱い。記事の中で数字が食い違っている箇所があり、[受検形式のページ](versions.md#問題数と制限時間の目安非公式)ではその点も明記しています

## 検索データ

- [よくある質問](faq.md)の質問は、Googleで「GAB 対策」と検索したときの「他の人はこちらも質問」から選びました（2026年11月25日、所在地は日本、言語は日本語）。

## このガイド独自の内容

解き方の手順、落とし穴の一覧、時間配分の目安、学習プラン、練習の目標、すべての練習問題は、このガイドのために書いたものです。日本SHLの公式な基準ではありません。練習問題はすべてオリジナルで、GABの実際の問題、日本SHLの資料、ほかの対策サイトから取ったものはありません。

## 提携関係について

このガイドは独立した学習ノートで、日本エス・エイチ・エル株式会社、SHLグループ、GABを利用する企業とは関係がなく、承認や後援も受けていません。GAB、玉手箱、OPQなどの名称は、それぞれの権利者の商標です。
