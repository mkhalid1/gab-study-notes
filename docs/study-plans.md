# 学習プラン：7日間と2日間

受検までの日数に合わせて、2つのプランを用意しました。どちらも、最初に[10分診断テスト](diagnostic.md)を解いて、苦手な科目を把握してから始めます。7日間プランは、1日45分から90分ほどを想定しています。

## 7日間プラン

| 日 | テーマ | やること |
|---|---|---|
| 1日目 | 現状把握 | [GABとは](test-overview.md)と[受検形式](versions.md)を読み、自分の受検形式を確認する。[診断テスト](diagnostic.md)を解く |
| 2日目 | 言語の線引き | [言語理解のページ](sections/gengo.md)を読み、練習問題5問を解く。間違えた問題は、根拠の一文を書き出して解き直す |
| 3日目 | 計数の式の立て方 | [計数理解のページ](sections/keisu.md)を読み、練習問題5問を解く。各問題の式を言葉で書き出す |
| 4日目 | 1回目の通し練習 | 時間を計って通しの模擬テストを解く（例：[PrepClubsの無料GAB形式模試](https://prepclubs.com/ja/gab-taisaku?utm_source=github&utm_medium=referral&utm_campaign=99ayax&utm_content=gab)）。科目ごとに正答率を出し、[時間配分のページ](timing.md)を読む |
| 5日目 | 苦手科目の補強 | 4日目に正答率が低かった科目のページに戻り、ミスしやすいポイントの一覧と自分のミスを照らし合わせる。新しい問題を20問以上解く |
| 6日目 | もう一方の科目と性格検査 | もう一方の科目のミスしやすいポイントを見直す。[性格検査のページ](personality-opq.md)を読み、形式を確認する。C-GABを受ける人は英語の準備もする |
| 7日目 | 2回目の通し練習と休息 | 午前中に2回目の通し練習をして、4日目と比べる。[受検当日のチェックリスト](test-day-checklist.md)を読み、夕方以降は勉強を切り上げる |

### 間違えた問題の見直し方

点数が伸びるのは、問題を解いている時間より、見直しの時間です。間違えた問題ごとに、次の3つを書き出してください。

1. どのルールを守れなかったか。例：「本文にないことを常識で補った」「前年ではなく今年の値で割った」。
2. 問題文のどこで気づけたか。気づくきっかけになった言葉や数字を見つけておきます。
3. 次から何を確認するか。「Aを選ぶ前に根拠の一文を示す」など、短い習慣にします。

この記録を1つのリストにまとめておくと、5日目には同じミスが2つか3つ繰り返されていることに気づくはずです。それを直すほうが、新しい問題を大量に解くより効果があります。

## 2日間プラン

受検の案内がすでに届いていて、締め切りが近い人向けです。

### 1日目：形式とルールを覚える

| ブロック | 時間 | やること |
|---|---|---|
| 1 | 10分 | [診断テスト](diagnostic.md)を解く |
| 2 | 20分 | 言語と計数のページの「問題の形式」と「ミスしやすいポイント」だけを読む |
| 3 | 40分 | 苦手な科目から順に、各ページの練習問題を解く。正解した問題の解説も読む |
| 4 | 60分 | 時間を計って通しの模擬テストを解く（例：[PrepClubsの無料GAB形式模試](https://prepclubs.com/ja/gab-taisaku?utm_source=github&utm_medium=referral&utm_campaign=99ayax&utm_content=gab)） |

### 2日目：弱点を直して受検に備える

| ブロック | 時間 | やること |
|---|---|---|
| 1 | 30分 | 1日目の通し練習で間違えた問題を、上の3つの質問で見直す |
| 2 | 20分 | [時間配分のページ](timing.md)を読み、1問あたりの上限時間を決める |
| 3 | 10分 | [性格検査のページ](personality-opq.md)で回答形式を確認する |
| 4 | 10分 | [受検当日のチェックリスト](test-day-checklist.md)を確認し、受検環境を整える |

## やらないほうがいいこと

- 解答を丸暗記する。本番で同じ問題が出る保証はありません。覚えるべきは答えではなく線引きと手順です。
- 前日に新しい問題を大量に解く。疲れが残るうえ、間違いが続くと自信を失います。前日は見直し中心にしてください。
- 性格検査で「求められていそうな人物像」を演じる。公式解説も、性格検査に共通の正解はないとしています。
- 他人に受けてもらう、AIに解かせる。不正であり、WebGAB SecureやC-GAB plusでは監視の対象です。
