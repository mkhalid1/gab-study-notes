# 玉手箱との違い

玉手箱Ⅲ（玉手箱）とGABは、どちらも日本エス・エイチ・エルの適性検査です。日本SHL自身が「玉手箱Ⅲと並び、当社のロングセラー適性検査の一つ」とGABを紹介しているように、同じ会社の別の商品です。どちらを受けるのかで準備の中身が変わるので、違いを押さえておきましょう。

## 公式情報での比較

日本SHLの製品ページと比較コラムの内容をまとめると、次のとおりです。

| 項目 | GAB（WebGAB） | 玉手箱Ⅲ |
|---|---|---|
| 言語の科目 | 言語理解（論理）：400〜800字程度の主張をもった文章の論理を読み取る | 言語理解（大意把握）：1000字程度のエッセイを読み、筆者の訴えたい趣旨を判断する |
| 計数の科目 | 計数理解（図表理解）：図表の読み取りと四則演算・百分率の計算 | 計数理解（四則逆算）：四則演算を組み合わせた等式の未知数を求める |
| 英語 | テストセンター方式のみ（50〜80語程度の英文） | あり（200〜400語程度の文章を読み、文章の論理と照らして正誤を判断） |
| 性格検査 | OPQ | OPQ |
| 所要時間合計 | 80〜90分（GAB） | 49分 |
| 実施形態 | 紙、Web、テストセンター | Web |
| 公式の位置づけ | ビジネスに必要な論理的な思考力を測定 | 受検者の能力適性を短時間で測定 |

出典：[GAB製品ページ](https://www.shl.co.jp/service/assessment/gab/)、[玉手箱Ⅲ製品ページ](https://www.shl.co.jp/service/assessment/tamatebako3/)、[SHLの適性検査（玉手箱Ⅲ・GAB・CAB・RAB）を徹底比較](https://www.shl.co.jp/column/perspective/220617ysato/)。2026年11月25日に確認。

## 言語の違い

GABの言語は、本文の論理から設問文が「正しい」「間違っている」「判断できない」のどれかを選びます。一方、玉手箱Ⅲの言語（大意把握）は、日本SHLの説明によると、枝葉のついた複雑な文章から、筆者がいちばん訴えたいことと、そうでないことを見分ける力を測ります。

つまり、GABは「書いてあることから何が言えるか」、玉手箱Ⅲの大意把握は「筆者の言いたいことは何か」に重心があります。GABの対策では、本文に根拠があるかどうかの線引き（[言語理解のページ](sections/gengo.md#問題の形式)）を最優先にしてください。

## 計数の違い

GABの計数は図表の読み取りです。玉手箱Ⅲの計数は、公式ページでは四則逆算（等式の中の未知数を求める問題）と紹介されています。GABの対策では、計算の速さよりも「表のどの数字を使い、何で割るか」を決める練習が中心になります（[計数理解のページ](sections/keisu.md#解き方の手順)）。

## 時間と量の違い

玉手箱Ⅲは、公式に言語・計数・英語が各約10分、所要時間合計49分とされています。GABは所要時間合計が80〜90分です。同じ会社のテストでも、GABのほうが長い時間をかけて受けることになります。集中力を保つ練習として、通しで時間を計って解く経験をしておくと安心です。

## 就活サイトでよく見る説明について

就活サイトや掲示板では「C-GABは玉手箱とほぼ同じ」「玉手箱の問題集でGABの対策ができる」といった説明を見かけることがあります。日本SHLの公開ページには、そうした説明はありません。公式の科目名と説明を見る限り、GABの言語は「論理」、計数は「図表理解」で、玉手箱Ⅲの「大意把握」「四則逆算」とは別の科目です。受ける予定のテストの形式に合わせて練習するのが確実です。

## 両方を受ける人へ

就職活動では、企業によって玉手箱Ⅲを課されたり、GABを課されたりします。両方を受ける予定があるなら、次の3点がおすすめです。

1. 受検案内でテスト名と形式を確認する。
2. 先に締め切りが近いほうの形式に集中する。
3. 言語で本文に根拠を求める習慣と、計数で分母を先に決める習慣は、どちらのテストでも役に立ちます。
