# 受検当日のチェックリスト

当日に慌てないための確認リストです。受検形式によって必要なものが違うので、自分の形式に当てはまる項目を確認してください。

## 前日まで

- [ ] 受検案内のメールを読み直し、テスト名、受検形式、締め切り日時を確認した
- [ ] Webで受ける場合：推奨環境（ブラウザ、OS）を確認し、パソコンの更新を済ませた
- [ ] WebGAB Secureの場合：Webカメラが使えることを確かめ、受検する部屋を決めた
- [ ] テストセンターの場合：会場と予約日時、本人確認に必要なものを確認した
- [ ] 電卓や筆記用具の扱いについて、案内に指示があるか確認した
- [ ] 十分に寝られるよう、前日は早めに切り上げる

## 受検の1時間前

- [ ] Webで受ける場合：通信が安定した場所で、ほかのアプリや通知を止めた
- [ ] メモ用紙と筆記用具を用意した（使ってよい場合）
- [ ] 電卓を使う場合：電池が切れていないか確かめた
- [ ] 会場で受ける場合：移動時間に余裕を持って出発した

## 開始直後

- [ ] 例題の画面で、科目ごとの問題数と制限時間を確認した
- [ ] 1問あたりの持ち時間を計算し、上限時間を決めた（[時間配分のページ](timing.md)）
- [ ] 言語の3つの選択肢（明らかに正しい・明らかに間違っている・判断できない）の意味を思い出した

## 受検中

- [ ] 言語：本文にないことを常識で補っていないか
- [ ] 言語：AやBを選ぶとき、根拠の一文を示せるか
- [ ] 計数：分母は正しいか（何に対する割合か）
- [ ] 計数：単位（百万円、％など）を読み違えていないか
- [ ] 1問に固執していないか。上限時間を超えたら次へ進む
- [ ] 紙のGABの場合：マークする欄の番号が問題番号と合っているか

## 受検後

- [ ] 受検完了の画面やメールを確認した
- [ ] 解きにくかった問題の種類をメモした（次に別の企業で受けるときの参考になります）

## 本番前の最後の練習

前日までに、時間を計った通しの練習を少なくとも1回はしておくと、当日のペースがつかみやすくなります。[PrepClubsの無料GAB形式模試](https://prepclubs.com/ja/gab-taisaku?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=gab)が使えます。
