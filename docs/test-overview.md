# GABとは：試験の全体像

GABは、日本エス・エイチ・エル（日本SHL）が提供する総合適性検査です。名前は Graduate Aptitude test Battery の略で、知的能力を測る「言語」と「計数」、仕事上の行動特性を測る性格検査（OPQ）でできています。このページでは、公式に公開されている情報だけで試験の全体像を整理します。

## 基本情報

| 項目 | 内容 |
|---|---|
| 提供元 | 日本エス・エイチ・エル株式会社 |
| 測定項目 | 言語・計数・英語・パーソナリティ（OPQ） |
| 所要時間合計 | 80〜90分（公式ページの表記） |
| ノルム（比較の基準集団） | 大卒 |
| 実施形態 | 紙、Web、テストセンター |
| 英語 | テストセンター方式のみ |
| 結果の表し方 | 標準点と呼ばれる10段階の得点 |
| 科目ごとの問題数と制限時間 | 公式の公開ページには記載なし（[受検形式のページ](versions.md#問題数と制限時間の目安非公式)に非公式の目安をまとめています） |

出典：[日本SHL GAB製品ページ](https://www.shl.co.jp/service/assessment/gab/)、[【公式解説】総合適性検査GABとは？](https://www.shl.co.jp/column/perspective/250905_gab/)。2026年11月25日に確認。

## 何を測るテストか

日本SHLは、GABを「ビジネスに必要な論理的思考力の測定に特化した適性検査」と説明しています。ポイントは、学力や知識ではなく、仕事で必要になる考え方を測っている点です。公式解説によると、もとはイギリスで開発された問題形式で、1980年代から日本語版が使われてきました。新卒・中途を問わず、職種や業界に関係なく使われています。

知的能力の2科目は、次のように説明されています。

- 言語理解テスト（論理）：400字から800字程度の「主張をもった文章」を読み、書き手が主張を支えるために用意したロジックをどこまで正しく理解しているかを測る。
- 計数理解テスト（図表理解）：図表を理解する力、四則演算や百分率の計算を速く正確に行う力、答えを出すためのいちばん効率のよい手順を考える力を測る。

## 科目の構成

| 科目 | 中身 | 解き方の詳細 |
|---|---|---|
| 言語理解 | 長文を読み、設問文が論理的に正しいか、間違っているか、本文だけでは判断できないかを選ぶ | [言語理解のページ](sections/gengo.md) |
| 計数理解 | 図表を読み取り、割合や増減率などを計算して選択肢から選ぶ | [計数理解のページ](sections/keisu.md) |
| 英語 | 50〜80語程度の英文を読み、設問の答えを英語で選ぶ。テストセンター方式のみ | [受検形式のページ](versions.md#英語テストセンター方式のみ) |
| 性格検査（OPQ） | 4つの行動の記述から、自分に最も近いものと最も遠いものを1つずつ選ぶ | [性格検査のページ](personality-opq.md) |

## 3つの受検形式

公式解説では、GABの実施形式は3つです。

1. Webテスト形式（WebGAB、WebGAB Plus One など）：自宅などのパソコンで受ける。
2. テストセンター形式（C-GAB plus）：全国のテストセンター会場で、厳格な本人確認のうえで受ける。英語が加わる。
3. マークシート形式（GAB）：紙の問題冊子とマークシートを使い、企業の会場などで受ける。

就活生のあいだでは、それぞれ「Web-GAB」「C-GAB」「紙のGAB（筆記GAB）」と呼ばれることが多いです。違いは[受検形式のページ](versions.md)で詳しく説明します。

## 結果はどう使われるか

結果は10段階の標準点で出ます。知的能力の得点に加えて、性格検査から「ヴァイタリティ」「チームワーク」などのコンピテンシー、将来のマネジメント適性、「営業」「研究／開発」などの職務適性が予測されます。企業は結果を選考だけでなく、面接で確認するポイントを絞ったり、配属を考えたりするのにも使います。詳しくは[採点と結果のページ](scoring.md)へ。

## 試験全体を通して大事なこと

GABの言語も計数も、問われているのは「与えられた情報から何が言えるか」です。言語では本文に書かれていないことを常識で補わない。計数では表のどの数字をどの数字で割るのかを先に決める。この2つを守るだけで、ミスの多くは防げます。

公式解説も、GABはちょっとした対策で得点が大きく変わるテストではないとしたうえで、問題形式、問題数、制限時間、解き方を理解して練習してから受けることを勧めています。本番の前には必ず例題が用意されています。

## 本番形式で練習する

形式に慣れたら、時間を計って通しで解いてみてください。[PrepClubsの無料GAB形式模試](https://prepclubs.com/ja/gab-taisaku?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=gab)は、言語52問・計数40問の計92問を60分で解く構成です。
