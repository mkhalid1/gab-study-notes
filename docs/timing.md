# 時間配分

GABの能力検査は、1問にかけられる時間が短いテストです。ここでは、時間の使い方を科目ごとに具体的に考えます。

## 前提：公式の数字と非公式の目安

日本SHLの公開ページにあるのは所要時間の合計（GABは80〜90分）だけで、科目ごとの問題数と制限時間は書かれていません。以下の計算は、就活サイトでよく紹介されるWeb-GABの目安（言語52問・25分、計数40問・35分）を仮に使ったものです。詳しくは[受検形式のページ](versions.md#問題数と制限時間の目安非公式)を見てください。

本番では、例題の画面で問題数と制限時間を必ず確認し、以下の考え方をその数字に当てはめてください。

## 1問あたりの持ち時間

| 科目 | 目安の問題数と時間 | 1問あたり |
|---|---|---|
| 言語 | 52問・25分 | 約29秒 |
| 計数 | 40問・35分 | 約53秒 |

言語は30秒弱、計数は1分弱です。言語は長文を読む時間も含めての数字なので、長文を最初から最後まで丁寧に読む余裕はありません。

## 言語のペース配分

- 長文は全体を一度読むのではなく、設問ごとに必要な箇所を読む。最初の設問で文章の構成（主張、理由、反論、結論）を大まかにつかみます。
- 1問40秒を超えたら、いちばん有力な記号を選んで進む。迷った問題は、根拠が見つからないならCの可能性が高いと考えます（[言語理解のページ](sections/gengo.md#解き方の手順)の手順6）。
- 同じ長文の設問をまとめて解く。長文が変わるたびに読み直しが必要になるので、1つの長文の設問は続けて片づけます。

## 計数のペース配分

- 1つの表の最初の設問で、単位、合計の行、年度の並びを確認する。ここに10秒使っても、2問目以降で取り返せます。
- 概算で決められる問題は概算で決める。選択肢の差が大きければ、細かい計算は不要です。
- 1問1分半を超えたら、概算でいちばん近い選択肢を選んで進む。

## 時間を失いやすい場面

| 場面 | 対策 |
|---|---|
| 言語で、本文を何度も読み返す | 設問のキーワードを決めてから本文を探す |
| 言語で、AかCかで迷い続ける | 根拠の一文を示せないならCにする |
| 計数で、表の単位を読み違えて計算し直す | 最初の設問で単位と注を確認する |
| 計数で、全部の選択肢を細かく計算する | 概算で2択まで絞ってから計算する |
| どちらでも、難しい1問に固執する | 時間の上限を決めて、超えたら進む |

## 時間を計って練習する

ペースは、読んで理解するだけでは身につきません。時間を計って、通しで解く練習が必要です。[PrepClubsの無料GAB形式模試](https://prepclubs.com/ja/gab-taisaku?utm_source=github&utm_medium=referral&utm_campaign=study-notes&utm_content=gab)は言語52問・計数40問の計92問を60分で解く構成なので、上の持ち時間の感覚をつかむのに使えます。
